Bahasa yang Digunakan dalam Pembuatan Web Ini

Web ini dibuat menggunakan beberapa bahasa dan teknologi, antara lain:

  • HTML (HyperText Markup Language): Digunakan untuk membuat struktur dan konten halaman web.
  • CSS (Cascading Style Sheets): Digunakan untuk mengatur tampilan dan desain halaman web.
  • JavaScript: Digunakan untuk menambahkan interaktivitas dan fungsionalitas dinamis ke halaman web.
